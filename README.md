# dotfiles

Personal setup for GitHub Codespaces. Codespaces clones this repo into every new Codespace and runs `install.sh`.

## What's here

- `claude/skills/`: personal Claude Code skills, linked into `~/.claude/skills/`.
  - `linear-board`: keeps a Linear project in sync with my open PR stacks.

## Secrets

Nothing secret lives in this repo, because it's public. API keys (e.g. `LINEAR_API_KEY`) are Codespaces user secrets.
